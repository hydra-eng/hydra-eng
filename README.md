## 🚀 Mission Critical Deployments (Flagship Projects)

<details open>
  <summary><b>🧊 CryoSentinel — Intelligent Cold Chain Guardian</b></summary>
  <br>
  An IP67 tamper-resistant industrial IoT tracker operating on ultra-low power (under 1 µA deep-sleep, ~36 days on 1000mAh). Designed a custom 2-layer PCB in KiCad integrating a LoRa SX1262 radio (15 km range) and an ATECC608A secure element for ECDSA P-256 cryptographic ledgers. Pushed telemetry to a FastAPI + WebSocket dashboard.
</details>

<details open>
  <summary><b>🎙️ Project VENUS — Offline Voice Assistant Ecosystem</b></summary>
  <br>
  A 100% offline, privacy-first voice ecosystem bridging an ESP32 smart-speaker with a local DeepSeek LLM. Engineered a Python WebSocket bridge that dynamically injects custom IoT schemas, allowing dual-domain control over Windows OS and Home Assistant smart devices simultaneously with zero cloud telemetry.
</details>

<details open>
