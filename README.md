## 🚀 Deep-Dive: Flagship Projects

### 🧊 CryoSentinel — Intelligent Cold Chain Guardian (FAR AWAY 2026 Hackathon)[cite: 1]
An IP67 tamper-resistant industrial IoT tracker operating on ultra-low power (under 1 µA deep-sleep, ~36 days on 1000mAh)[cite: 1].
*   **Hardware Architecture:** ESP32-C3, LoRa SX1262 radio (865 MHz, 15 km range), u-blox MAXM10S GPS (<1.5 m accuracy, sub-2-second warm-start fix)[cite: 1].
*   **Cryptographic Security:** ATECC608A secure element signing a SHA-256 hash-chained audit ledger with ECDSA P-256[cite: 1].
*   **Sensing & Telemetry:** ±0.2°C temp / ±2% RH accuracy (SHT40), 3-axis ±16g accelerometer for shock/tamper detection, and zero-power NFC config (ST25DV)[cite: 1].
*   **Software Backend:** Custom 2-layer PCB designed in KiCad streaming to a Python FastAPI + WebSocket breach-telemetry dashboard[cite: 1].

### 🎙️ Project VENUS — Offline Voice Assistant Ecosystem[cite: 1]
A 100% offline, privacy-first voice ecosystem where zero voice data ever leaves the local network[cite: 1].
*   **AI Integration:** Bridged an ESP32 smart-speaker with a locally hosted DeepSeek LLM via Ollama[cite: 1].
*   **Dynamic Schemas:** Python WebSocket bridge dynamically injects custom IoT tool schemas into the LLM at runtime with keep-alive handling[cite: 1].
*   **Dual-Domain Control:** Seamlessly commands Windows OS automation and Home Assistant smart devices simultaneously (e.g., "Open calculator and turn on lights") with no cloud round-trip[cite: 1].

### 🔋 DES-TWIN — Digital Twin Battery-Swap Network[cite: 1]
A massive full-stack digital twin discrete-event simulation modeling city-wide EV infrastructure[cite: 1].
*   **Simulation Kernel:** SimPy modeling EV battery-swap stations using non-homogeneous Poisson demand and CC-CV Li-ion charging physics[cite: 1].
*   **Visualization Stack:** FastAPI backend orchestrating the kernel connected to a React + Vite + deck.gl WebGL frontend for geospatial A/B counterfactual testing across wait times and charger utilization[cite: 1].
